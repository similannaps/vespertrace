# VESPERTRACE — Originality & Game Identity

**Game Title:** VESPERTRACE  
**Genre:** A Shadow-Based 2D Puzzle Game  
**Technology:** Phaser 3 + TypeScript + Vite  
**Tagline:** *Every step leaves something behind.*

VESPERTRACE เป็นเกมปริศนา 2D ที่เน้นการวางแผนการเคลื่อนที่บนกระดาน ผู้เล่นต้องพิจารณาตำแหน่งของตัวละคร เงา และองค์ประกอบต่าง ๆ ภายในด่าน เพื่อหาวิธีแก้ปริศนาและไปถึงเป้าหมาย

เอกสารนี้อธิบายแนวคิดหลัก เอกลักษณ์ในการออกแบบ และทิศทางการพัฒนาของเกม

---

## 1. Core Concept

แนวคิดหลักของ VESPERTRACE คือ

> **Every step leaves something behind.**

ทุกก้าวทิ้งร่องรอยไว้บนกระดาน

การเคลื่อนที่แต่ละครั้งมีความสำคัญต่อการแก้ปริศนา ผู้เล่นต้องวางแผนอย่างรอบคอบและพิจารณาผลที่เกิดขึ้นจากตำแหน่งต่าง ๆ ภายในด่าน

เกมมุ่งเน้นการคิดวิเคราะห์ การทดลอง และการวางแผน มากกว่าการต่อสู้หรือการใช้ปฏิกิริยาตอบสนองที่รวดเร็ว

---

## 2. Game Design Principles

### 2.1 Grid-Based Movement

การเคลื่อนที่บนกริดทำให้ผู้เล่นสามารถวางแผนทีละขั้น และประเมินผลของการเดินแต่ละครั้งได้อย่างชัดเจน

### 2.2 Shadow-Based Mechanics

เงาเป็นองค์ประกอบสำคัญของเกมที่เชื่อมโยงกับการเคลื่อนที่และการแก้ปริศนา ไม่ได้มีไว้เพื่อความสวยงามเพียงอย่างเดียว

### 2.3 Strategic Problem Solving

ผู้เล่นต้องคิดถึงผลลัพธ์ของการกระทำแต่ละครั้ง เพื่อเลือกเส้นทางและวิธีแก้ปริศนาที่เหมาะสม

### 2.4 Level Progression

ระบบเลือกด่านและความคืบหน้าช่วยให้ผู้เล่นสามารถเล่นตามลำดับ และเรียนรู้กลไกของเกมผ่านการเล่นแต่ละด่าน

### 2.5 Visual Identity

เกมใช้บรรยากาศสีเข้มอมครามและม่วง ตัดกับแสงสีมิ้นต์และม่วง เพื่อสร้างเอกลักษณ์ทางภาพที่สอดคล้องกับแนวคิดเรื่องเงาและร่องรอย

การออกแบบให้ความสำคัญกับความชัดเจนของข้อความ ความแตกต่างระหว่างองค์ประกอบ และความสะดวกในการทำความเข้าใจหน้าจอ

---

## 3. Current Project Scope

VESPERTRACE พัฒนาด้วย Phaser 3, TypeScript และ Vite โดยมีระบบหลักดังนี้

- หน้าเริ่มเกม (Title Screen)
- ระบบเลือกตัวละคร
- ระบบเลือกด่าน
- ระบบความคืบหน้าและการปลดล็อกด่าน
- ด่านปริศนาที่เล่นได้ 3 ด่าน
- ระบบเคลื่อนที่บนกริด
- กลไกเงาที่ใช้ในการแก้ปริศนา
- องค์ประกอบปริศนา เช่น สวิตช์ ประตู และทางออก

ขอบเขตดังกล่าวอธิบายระบบของโปรเจกต์ในปัจจุบัน โดยสามารถเพิ่มเติมกลไก ด่าน และเนื้อหาใหม่ได้ในอนาคต

---

## 4. Visual Direction

แนวทางการออกแบบภาพของ VESPERTRACE ประกอบด้วย

- **Background:** สีดำอมครามและม่วงเข้ม
- **Primary Accent:** สีมิ้นต์ `#12f7c8`
- **Secondary Accent:** สีม่วง `#7c6cff`
- **Heading Font:** Syne
- **Supporting Font:** IBM Plex Mono
- **Visual Style:** Minimal, dark, atmospheric และเน้นแสงจากองค์ประกอบภายในเกม

การใช้สีและตัวอักษรมีเป้าหมายเพื่อสร้างบรรยากาศที่จดจำได้ พร้อมรักษาความชัดเจนในการเล่น

---

## 5. Originality and Design Identity

เอกลักษณ์ของ VESPERTRACE อยู่ที่การนำแนวคิดเรื่องเงาและร่องรอยมาผสานกับการแก้ปริศนาบนกริด

องค์ประกอบที่ใช้กำหนดทิศทางการออกแบบ ได้แก่

1. การเคลื่อนที่ที่ต้องอาศัยการวางแผน
2. การใช้เงาเป็นส่วนหนึ่งของกลไกปริศนา
3. การออกแบบด่านที่ส่งเสริมการคิดวิเคราะห์
4. การจัดลำดับความคืบหน้าผ่านระบบด่าน
5. การสร้างบรรยากาศด้วยโทนสีเข้มและแสงสีมิ้นต์กับม่วง

องค์ประกอบเหล่านี้เป็นแนวทางในการพัฒนาเอกลักษณ์ของโปรเจกต์ ทั้งนี้ แนวคิดทั่วไปและกลไกแต่ละประเภทอาจพบได้ในเกมอื่นเช่นกัน จึงไม่ถือเป็นการยืนยันว่าทุกองค์ประกอบมีความใหม่หรือเป็นเอกสิทธิ์เฉพาะ

---

## 6. Development Direction

แนวทางการพัฒนาต่อไปสามารถประกอบด้วย

- เพิ่มจำนวนด่านและความหลากหลายของปริศนา
- ปรับสมดุลความยากของแต่ละด่าน
- ปรับปรุงการแสดงผลและประสบการณ์ผู้เล่น
- เพิ่มคำแนะนำการเล่นที่เข้าใจง่าย
- ทดสอบระบบและแก้ไขข้อผิดพลาด
- จัดทำเอกสารและสื่อประกอบสำหรับ Portfolio

การเพิ่มเติมระบบจะพิจารณาจากความเหมาะสมกับแนวคิดหลักและประสบการณ์การเล่นที่ต้องการนำเสนอ

---

## 7. Project Purpose

VESPERTRACE เป็นโปรเจกต์พัฒนาเกมส่วนบุคคลที่สร้างขึ้นเพื่อฝึกทักษะการเขียนโปรแกรม การออกแบบระบบเกม และการพัฒนา Interactive Experience ด้วยเทคโนโลยีเว็บ

โปรเจกต์นี้ยังสามารถใช้เป็นผลงานใน Portfolio เพื่อแสดงกระบวนการพัฒนา การออกแบบกลไก และการนำเทคโนโลยีมาประยุกต์ใช้กับเกมปริศนา 2D

---

## 8. Summary

VESPERTRACE เป็นเกมปริศนา 2D ที่มุ่งเน้นการวางแผนและการใช้กลไกเงาในการแก้ปริศนา พัฒนาด้วย Phaser 3, TypeScript และ Vite พร้อมแนวทางภาพที่ใช้พื้นหลังสีเข้มและแสงสีมิ้นต์กับม่วง

**VESPERTRACE — Every step leaves something behind.**
